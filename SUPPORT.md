# Support

Use [GitHub Issues](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection/issues) for reproducible bugs, compatibility questions, and feature proposals. Search existing issues first and include the package version, target framework, configuration details, and a minimal reproduction where possible.

Security reports belong in [GitHub Security Advisories](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection/security/advisories/new), not public issues. Community support is provided on a best-effort basis without an SLA.
