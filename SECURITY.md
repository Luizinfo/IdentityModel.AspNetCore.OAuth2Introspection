# Security policy

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection/security/advisories/new).

Include affected versions, impact, reproduction details, and any suggested mitigation. Do not disclose the issue publicly until maintainers have had an opportunity to investigate and coordinate a fix. No response or remediation SLA is promised.
