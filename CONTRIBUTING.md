# Contributing

Contributions are welcome through issues and pull requests in the [current repository](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection).

Before opening a pull request, describe the intended behavior, keep changes focused, preserve public compatibility unless a breaking change is explicitly discussed, and run the Release build and all tests. By contributing, you agree that your contribution is licensed under [Apache-2.0](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection/blob/main/LICENSE).

For vulnerabilities, do not open a public issue; follow the [security policy](https://github.com/Luizinfo/IdentityModel.AspNetCore.OAuth2Introspection/blob/main/SECURITY.md).
